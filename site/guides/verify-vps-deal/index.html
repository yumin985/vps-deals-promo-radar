Buying checklist

How to verify a VPS deal before ordering

A low headline price is only useful when you can trace it to a public provider page and understand what was checked.

1. Start with the official source

Open the provider URL attached to the listing. On vps-deals, every active offer carries an offer URL, a source URL, and a fetched-at timestamp. Those fields come from the public provider pages recorded in the site dataset.

2. Check the plan name and price together

Match the plan title to the price shown on the provider page. Each card links back to its source. If access is blocked or a price cannot be parsed reliably, the plan is omitted from the refreshed comparison rather than carried forward as current.

3. Read the billing terms

Look for the billing term, renewal price, taxes, setup fees, and any introductory period. If the provider does not publish a verified expiration date, the listing says so instead of guessing one.

4. Treat the timestamp as a freshness check

A fetched-at timestamp tells you when the public page was checked. It does not guarantee that the provider still shows the same price now, so refresh the official page before paying.

5. Compare like with like

Use the compare page for a first pass, then verify CPU, memory, storage, traffic, location, and support terms on the provider page. If a field is missing from the public source, leave it unfilled rather than infer it.

Official pages to check

Open a provider from the configured official sources. The comparison only shows fields that were verified; a missing expiry date means unknown, not an unlimited promotion. Read how to compare prices with different check times before treating any headline price as a current quote.
